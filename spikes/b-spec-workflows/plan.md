# Spike B plan

Hypothesis: existing spec/workflow packages can cover idea→brief→architecture→
design context→specification→tasks→implementation→review→acceptance without a
Rig workflow engine. Timebox: 3–4 developer-days. Started after C completed and
PR #4 merged on 2026-09-14.

Use the same [synthetic feature](../../fixtures/b-workflow/feature-brief.md) for
Spec Kit, BMAD, OpenSpec and Superpowers. Pin current official releases/commits
before use; verify actual help and package integrity. Each candidate uses its
own ignored installation fixtures and small checked-in synthetic output.

Stop a native model session if credentials/payment would be required, but
continue an explicitly manual-load Codex skill/template execution and record
that narrower surface. Never invent native artifact generation, board export,
approval, uninstall or update behavior. Board export may be tested against
synthetic GitHub issues in this private lab only. No Jira RP or production writes.

Collect both Rig installation orders and applicable repeat/dry-run/edit/delete/
update/uninstall behavior for overlapping candidates. Native lifecycle evidence
from A/F is reused only for the exact surface actually tested there. A shared
acceptance runner independently evaluates implementations. Review artifacts
and incremental restart/idempotency, then select only layers with measured value.
