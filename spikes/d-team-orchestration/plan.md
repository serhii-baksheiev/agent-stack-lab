# Spike D plan

Hypothesis: native harness agents and an external board provide explainable team work without a Rig scheduler. Timebox 3–5 developer-days; stop an integration on unavailable authorization/subscription or failed critical ownership guarantee, retain bounded negative evidence. No AMQ/AMAQ, private Jira data, production changes or model inference.

First test actual GitHub issue conditional updates and real dependency links in this private laboratory. If issue mutation lacks compare-and-swap, test the smallest existing GitHub atomic reference primitive before considering any new lease layer. A lab-only lease proof must distinguish cooperative fencing from hard protection against direct privileged pushes/merges, and must not become a queue or workflow engine.

Use synthetic issue/spec/task IDs, two independent command clients, separate worktrees/branches, conflicting PRs, a third external PR, reviewer feedback, crash/expiry/reclaim, stale-owner rejection and event replay. Close all created issues/PRs after collecting evidence. Native Claude→Codex model execution is unverified unless actually invoked; a persisted handoff fixture only proves state readability.

Independently inspect current native team capabilities, Symphony and OpenHands, pin official sources/licenses/activity and execute available source/CLI tests in isolated fixtures. Jira remains untested because only this lab repository is authorized for mutations. Report ready-orchestrator behavior separately from a synthetic adapter proof.
