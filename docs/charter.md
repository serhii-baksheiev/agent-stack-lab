# Charter

Agent Rig is evaluated as a thin installer, compatibility checker, configurator and updater of existing Claude Code and Codex capabilities. Prefer native capabilities and mature upstream tools. No custom universal DSL, queue, memory engine, provider SDK or orchestrator without experimental evidence that alternatives fail.

Only this private repository may be modified. All experiments use synthetic data in ignored `.lab-runs/` repositories. Never install payload at the laboratory root, commit installed payload, credentials, real memory, runtime databases or production source. Published `create-agent-rig@0.9.0` is immutable; registry integrity must be checked before executing it.

Order: A (1–2 developer-days), F (1 day), C (1–2 days), B (3–4 days), E (2–3 days), D (3–5 days). These are maximum investigation budgets, not claims about elapsed work. Each report records actual timestamps and scope. Stop a scenario on unavailable required credentials, unverified baseline integrity, safety boundary violations, license uncertainty requiring owner judgment, or exhausted timebox. Continue independent scenarios. Never represent an offline substitute as a live integration pass.

Branches and PRs: `lab/bootstrap`, `spike/a-spec-kit-manifest`, `spike/f-native-projection`, `spike/c-figma`, `spike/b-spec-workflows`, `spike/e-memory`, `spike/d-team-orchestration`, `lab/final-recommendation`. Independent agent review and green CI precede autonomous laboratory merges to `master`. Production changes are proposals only.

Task authority belongs to an external board, blockers to issue links, code state to GitHub branches/PRs/worktrees. Native tasks are session views; memory is context. Rig is not a scheduler.
